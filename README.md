# Курсовая работа по компьютерной графике

Интерактивный конструктор планетных систем с трёхмерной визуализацией.

## Структура

```text
CG_coursework_IU7_2028/
├── program/     # Программа на C++ и Qt, CMakeLists.txt и интерфейс
├── report/      # Исходник РПЗ, задание и иллюстрации
└── .vscode/     # Общие настройки работы в VS Code
```

Для работы открой корень репозитория в VS Code.

- РПЗ: [report/rpz.tex](report/rpz.tex), инструкция — [report/README.md](report/README.md).
- Программа: [program/CMakeLists.txt](program/CMakeLists.txt), исходное описание проекта — [program/README.md](program/README.md).

## Сборка

РПЗ собирается через LaTeX Workshop: `Ctrl+Alt+B`, просмотр PDF — `Ctrl+Alt+V`.
Результат находится в `report/build/rpz.pdf`.

Для программы нужны CMake, компилятор C++20 и Qt6 с компонентами Core, Gui,
Widgets и OpenGLWidgets. Из корня репозитория:

```sh
cmake -S program -B program/build
cmake --build program/build
```

Настройки CMake Tools в `.vscode/settings.json` указывают на те же папки.
Исходная конфигурация C++ для Linux сохранена в `program/.vscode/`;
она применяется, если открыть `program/` как отдельную папку в VS Code.
При работе непосредственно из `program/` команды остаются привычными:

```sh
cmake -S . -B build
cmake --build build
```

## Локальные материалы и Git

Работа над РПЗ и структурой выполняется в ветке `docs`, созданной от `dev`.
Исходные файлы программы перенесены целиком, их содержимое не менялось.

`report/_local/` содержит ГОСТы, старые черновики и вспомогательные материалы.
Старая Linux-сборка из репозитория сохранена в
`program/_local/build-from-repository/`, а готовый исполняемый файл — в
`program/_local/PlanetSystemDesigner`. Её кэш содержит пути к другому компьютеру,
поэтому для новой сборки используется чистая папка `program/build/`.

Папки `_local/`, результаты сборки программы и РПЗ исключены через `.gitignore`.
После переноса старые отслеживаемые артефакты отмечаются Git как удалённые
со старых путей; их локальные копии в архиве не добавляются в новый коммит.
В репозиторий включаются исходники, задание, иллюстрации и настройки редактора.
